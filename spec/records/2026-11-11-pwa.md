## Implementation

The README now leads with the app, features and CI/live-app/Storybook/license
badges, with token, storage, installation and development guidance.

A base-aware manifest, Lapis install icons and one app-owned worker provide
installation, isolation headers and a versioned public asset cache. Offline
startup presents the shared reconnect shell without authenticating or exposing
account data. Credentials remain in their dedicated remembered-session record;
private response caching remains in the separate token-partitioned Turso DB.

The worker caches only the generated public asset inventory with omitted
credentials; API/authenticated/query/Storybook requests are excluded. Waiting
updates require explicit reload, disabled during connection or commands. Older
tabs retain their immutable assets, then obsolete caches are pruned. The old
header-only worker migrates automatically; isolation reload is bounded per tab.
Hash navigation preserves the selected view on reload and back.
